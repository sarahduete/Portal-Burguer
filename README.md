# 🍔 Portal Burguer

**Site para hamburgueria**

O Portal Burguer é um projeto desenvolvido com a proposta de criar um site para uma hamburgueria, apresentando seus produtos e criando uma identidade visual que combinasse com o segmento.

🔗 **[Acessar o site](https://portalburger.netlify.app/)**

---

## 📖 Sobre o projeto

A ideia do Portal Burguer surgiu como uma oportunidade de desenvolver um site para o segmento alimentício. O objetivo era criar uma página que apresentasse a hamburgueria de maneira atrativa e organizada, facilitando a visualização das informações pelos visitantes.

## 💻 Como foi desenvolvido

O desenvolvimento começou com a definição da identidade visual. Pensei em uma aparência que combinasse com o universo das hamburguerias, utilizando elementos visuais que ajudassem a destacar os produtos e a proposta da marca.

Em seguida, comecei a estruturar as páginas utilizando HTML, organizando as seções e os conteúdos do site.

Depois, trabalhei no CSS para construir a aparência da página, ajustando cores, fontes, espaçamentos e a disposição dos elementos.

Durante o processo, fui realizando ajustes na estrutura e no visual para deixar a navegação mais agradável e manter uma identidade visual consistente.

## ⚙️ Funcionalidades e seções

- Apresentação da hamburgueria.
- Exibição dos produtos.
- Seção de promoções.
- Área de pedidos e informações.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
